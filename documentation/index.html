Introduction

VoltFleet is a premium admin dashboard template designed specifically for electric vehicle fleet management platforms. It provides a comprehensive set of pages, components, and data visualizations to help you build powerful fleet management software faster.

Built on the latest Next.js 14 App Router, fully typed with TypeScript, and styled with Tailwind CSS + ShadcnUI, VoltFleet is production-ready out of the box.

10 fully built pages, 30+ reusable components, dark/light mode, responsive layout, interactive charts, live tracking UI, geofence configuration, RBAC matrix, and shift management.

03

Installation

Step 1 — Extract the ZIP

Extract the downloaded voltfleet-admin.zip file to your desired location.

Step 2 — Open in Terminal

Terminal 
# Navigate into the project folder
cd voltfleet-admin

Step 3 — Install Dependencies

npm 
npm install

# or with yarn
yarn install

# or with pnpm
pnpm install

Step 4 — Start Development Server

Terminal 
npm run dev

Open http://localhost:3000 in your browser. You should see the VoltFleet dashboard.

Step 5 — Build for Production

Terminal 
npm run build
npm run start
⚠️
Do NOT include node_modules
The ZIP does not include node_modules. You must run npm install after extracting. This keeps the file size small and ensures you get the latest compatible packages.

Theming

VoltFleet supports Dark and Light mode out of the box via next-themes and a custom ThemeProvider.

How Theming Works

The theme is stored in localStorage and applied via a CSS class on the <html> element. Components use the useTheme() hook to conditionally apply classes.

Usage Example 
import { useTheme } from '@/components/theme-provider';

const { theme } = useTheme();
const isDark = theme === 'dark';

// Use in className
<div className={isDark ? 'bg-gray-900' : 'bg-white'}>

Customizing Colors

Primary brand colors are defined in tailwind.config.ts. Look for the volt and cyber color scales:

tailwind.config.ts 
colors: {
  volt: {
    '400': '#a3ff47',   // Primary green accent
    '500': '#7fd625',
  },
  cyber: {
    '400': '#22d3ee',   // Cyan accent
  }
}

Adding a New Page

Terminal 
# 1. Create the folder and page file
mkdir app/reports
touch app/reports/page.tsx

# 2. Add the route to the sidebar in components/sidebar.tsx

Replacing Mock Data

All pages use local mock data arrays defined at the top of each page.tsx file. Replace these with your API calls using fetch, axios, or SWR:

Example API integration 
// Replace mock data with a real API call
const [vehicles, setVehicles] = useState([]);

useEffect(() => {
  fetch('/api/vehicles')
    .then(res => res.json())
    .then(data => setVehicles(data));
}, []);
